# 接口参考

所有接口都要求请求头 `X-Wangsi-Token`，token 在计算主机上通过 `bin/wangsictl token` 获取。

## HTTP API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/overview` | 设计、主机、调度池、最近作业概要 |
| GET | `/api/workspace?case=` | 3D 评审工作区的状态列表与签核判定 |
| GET | `/api/scene?case=&label=` | 3D 场景（gzip JSON，格式见下文） |
| GET | `/api/design/<case>` | 设计信息、标准状态、候选池、评测历史 |
| GET | `/api/evals?case_name=&kind=&origin=&v6=1` | 评测记录 |
| GET | `/api/jobs`、`/api/job/<id>`、`/api/job/<id>/events?after=` | 作业、步骤和事件 |
| GET | `/api/stream?job=&token=` | 作业事件流（SSE） |
| GET | `/api/progress?run_id=` | 评测器实时进度（阶段、每片 die 的布线违例轨迹） |
| GET | `/api/tools`、`/api/skills`、`/api/llm_calls`、`/api/host` | 工具注册表、经验库、模型调用、主机状态 |
| POST | `/api/jobs` | 提交作业：`{"kind":"eco_eval|eco_closure|block_flow","params":{...},"title":""}` |
| POST | `/api/job/<id>/cancel`、`/api/step/<id>/retry` | 取消作业、重试步骤 |
| POST | `/api/tools/<name>` | 同步调用只读工具 |
| POST | `/api/catalog/refresh` | 刷新数据目录 |

## MCP

```bash
python wangsi.py mcp
```

会输出客户端配置。暴露的工具包括：全部只读工具、`submit_eco_eval`、`submit_eco_closure`、`submit_block_flow` 和 `job_status`。

## 3D 场景格式

坐标单位为 0.01 µm（`routes` 为 0.1 µm）。

| 字段 | 内容 |
|---|---|
| `die` | `[w, h]` |
| `layers` | 层名，按物理堆叠顺序（底层 metal1..10、hbt、上层 metal11..20） |
| `cells` | `[x, y, w, h, tier, class]`，class：0 逻辑、1 触发器、2 缓冲器、3 时钟、5 宏单元 |
| `macros` | `[x, y, w, h, tier, name]` |
| `hbt` | `[x, y, net]` |
| `routes.layers[i]` | base64 编码的 uint16 小端数组，每 4 个数为一段 `x1, y1, x2, y2` |
| `nets` | 关键线网：`wires [x1, y1, x2, y2, layer]`、`conn [inst, pin, x, y, tier]`、`fanout`、`length_um` |
| `paths` | 违例路径：`slack`、`start`、`end`、`pts [x, y, tier, stage_delay]` |
| `endpoints` | `[name, x, y, tier, slack]` |
| `drc` | `[x1, y1, x2, y2, layer, type]` |
| `guide_diff` | `changed_nets`，以及每个线网新增 / 删除的 guide 框 |
| `metrics`、`drt_trace` | 评测器指标；每片 die 的详细布线违例轨迹 |
