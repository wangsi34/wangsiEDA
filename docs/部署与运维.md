# 部署与运维

如需在 Mac 上查看自带示例，请按[中文 README 的本地演示步骤](../README.zh-CN.md#先看演示不需要任何私有数据)运行 `python3 wangsi.py demo`。下文介绍如何部署执行作业的 Linux 计算主机。

## 推荐拓扑

| 位置 | 部署内容 |
|---|---|
| 计算主机（Linux） | wangsid 服务、作业引擎、EDA 工具、评测器、数据库 |
| 用户工作站 | 浏览器，以及启动器 `wangsi.py`（负责建立 SSH 隧道） |
| 不需要联网的评审人员 | 只读的本地数据包（双击 `打开念思.html`） |

## 以系统服务方式运行

```bash
sudo mkdir -p /opt/wangsieda /etc/wangsieda
sudo cp -r cloud/* /opt/wangsieda/
sudo cp cloud/deploy/wangsieda@.service /etc/systemd/system/wangsieda@.service
sudo install -m 600 /dev/null /etc/wangsieda/llm.env   # 写入 WANGSI_LLM_API_KEY / WANGSI_LLM_BASE_URL
sudo systemctl daemon-reload && sudo systemctl enable --now wangsieda@<运行用户>
```

不使用 systemd 时，可以用 `bin/wangsictl start|stop|restart|status` 管理服务。

## 日常运维

| 任务 | 方法 |
|---|---|
| 查看服务 | `bin/wangsictl status`；日志在 `var/daemon.log` |
| 查看作业 | `python3 -m wangsieda.cli jobs`、`job <id>`、`events <id>` |
| 失败步骤重试 | 控制台中点选该步骤 → “重试此步骤”，或 `cli retry <step_id>` |
| 取消作业 | 控制台作业页“取消作业”；运行中的步骤会收到 SIGTERM |
| 刷新数据目录 | 每 30 分钟自动刷新，也可手动运行 `bin/wangsictl refresh` |
| 备份 | 备份 `var/wangsi.db`（SQLite WAL 模式，建议先 `sqlite3 var/wangsi.db ".backup out.db"`）和 `jobs/` |
| 升级 | 用新版本覆盖代码 → `bin/wangsictl selftest` → `bin/wangsictl restart`。运行中的步骤会被自动接管 |
| 释放空间 | `eval_cleanup` 会自动删除评测中间数据库；`jobs/` 可按作业归档 |

## 容量与并发

- 评测器并发由 `pools.evaluator` 控制：`own` 是本平台的上限，`global` 是全机上限（统计所有 `marker` 匹配的进程）。
- 主机准入门由 `host_gate` 控制：负载、剩余磁盘、可用内存任一项不满足时，评测会排队，并在作业时间线中显示等待原因。
