# 配置参考（wangsi_config.json）

| 键 | 必填 | 说明 |
|---|---|---|
| `project_root` / `results_dir` / `scan_roots` / `scan_exclude` | 是 | 历史评测结果所在目录（只读扫描）及排除规则 |
| `normalized_states_json` | 是 | 标准签核状态表：`{"states":[{"case","method","variant","candidate","metrics":{...}}]}` |
| `gate_bounds_json` | 是 | 签核门：`{"designs":{"<case>":{"v6_bounds":{...}}}}`，字段见下表 |
| `design_registry_module` | ECO 必填 | Python 模块，提供 `DESIGNS[case]`（键：`sel`、`ctx`、`policy`、`readback`、`timeout`、`x0_tns`、`role`）、`fb()` 构建器工厂和 `cand_context(case, program)` |
| `eco_builder_module` | ECO 必填 | 构建器，提供 `validate(ctx)`、`prepare(ctx, out_dir)`、`execute(out_dir)`，最后一个返回结果 JSON 路径，其中 `status` 为 `BUILT_VALIDATED` 表示成功 |
| `rootfs` / `runtime_dir` | ECO 必填 | 评测器运行环境与运行目录 |
| `platform_dir` | 3D 必填 | 工艺平台目录（含 `lef_bottom/`、`lef_upper/`、`lef/`） |
| `x0_runs` | 3D 必填 | 每个设计的初始状态评测目录（含 `results/.../6_final.def` 等） |
| `oss_cad_bin` / `openroad_env` / `nangate45_dir` | 模块流程必填 | Yosys、Icarus、Verilator 与 OpenROAD 的位置 |
| `llm_env_file` / `llm_model` | Agent 必填 | 密钥文件（`WANGSI_LLM_API_KEY`、`WANGSI_LLM_BASE_URL`）与模型名称；兼容 OpenAI `/chat/completions` 接口 |
| `llm_extra` / `llm_max_tokens` / `llm_timeout_s` | 否 | 合并进请求体的额外字段（如 DeepSeek 思考模式 `{"thinking": {"type": "enabled"}, "reasoning_effort": "high"}`）、最大输出 token（默认 6000，思考模式建议 16000）、单次超时秒数（默认 300）。服务端拒绝 JSON 模式时自动去掉 `response_format` 重试一次 |
| `pools` / `host_gate` / `host_disk_path` | 否 | 调度池与主机准入门 |
| `cases` / `case_aliases` / `port` | ECO 必填 | 设计列表（界面菜单、工具参数校验都由它生成；不填则只启用模块流程与 DEF 导入）、别名、端口 |
| `scene_cases` | 否 | 可生成 3D 场景的设计，默认取 `x0_runs` 的键 |
| `readbacks` | 否 | 同状态 hold/clock 回读：`{"<case>": {"derivation": 派生工具名, "args": "result_workroot" 或 "final_dir", "runtime_subdir": 目录名}}`；未列出的设计在签核门中报 `clock_UNMEASURED` |
| `clock_name` / `clock_period_ns` | 否 | 回读结果中的时钟名（默认 `CLK`）；各设计时钟周期（只用于 3D 讲解中的文字） |
| `program_tag_regex` | 否 | 候选程序标签的正则，用于“不重放”检查（默认 `F` 加 4–5 位数字） |
| `runtime_scan_subdirs` | 否 | 运行目录下额外扫描的子目录，用于识别已经跑过的程序 |
| `evaluator_marker` | 否 | 评测器脚本名中的子串，用于统计整台主机上运行中的评测器（默认 `evaluator`） |
| `derivations` | ECO 必填 | 派生工具：`{"<name>": {"source": 源脚本, "replacements": [[源字面量, 新字面量], ...]}}`。每个源字面量必须在源文件中只出现一次；新字面量可以使用 `{DERIVED}` 占位符 |
| `redact_terms` | 否 | 导出快照时额外隐藏的词 |
| `use_default_prompts` / `default_prompt_variant` | 否 | 是否使用内置提示词（默认是）；版本 `"A"`/`"B"`/`"C"`，或按 Agent 指定 `{"rtl_debug": "C"}` |

## 签核门字段（v6_bounds）

| 字段 | 判定 |
|---|---|
| `wns_inherited` | 建立时间最差裕量不得低于该值 |
| `drc_total_inherited` / `drc_Short` / `drc_Cut_Short` | DRC 总数、Short、Cut Short 不得超过 |
| `hold_tns_safety` / `hold_wns_safety` | 保持时间 TNS / WNS 不得低于 |
| `wirelength_inherited` | 线长不得超过 |
| `clock_delta_allow_ps` | 各时钟边沿延迟 / 偏斜相对 X0 的允许增量（ps） |
| `area_inherited` / `instance_count_inherited` | 可选；面积、单元数不得超过（需要评测指标中提供 `area` / `instances`） |
| HBT | 超额数必须为 0 |

缺少任一必需指标（WNS、DRC、Short、Cut Short、hold、线长、时钟增量）时判为不通过，不会默认放行。

## 评测器结果约定

评测器每次运行需要输出：
- `reports/metrics.json`（`tns_ns`、`wns_ns`、`drc`、`drt_wirelength_um`、`hbt_excess_count`、`legal`）；
- `5_route_drc.rpt`；
- `results/.../6_final.def`、`violated_paths`、`hbt_net_merge.tsv`、`route.guide`；
- `logs/.../6_report.json`。

OpenROAD-flow-scripts 和 Open3DBench 的标准输出满足这一约定。
